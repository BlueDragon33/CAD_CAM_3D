# WP-E4A — Verified Registration Pin Foundation

Status: **ACTIVE**
Parent: `WP-E4-SPLIT-SEAM-JOINING-FOUNDATION`
Blueprint zone: Floors 51–60 — Manufacturing Intelligence

## User value

Provide an optional, bounded alignment aid for simple single-axis split parts so the pieces can register repeatably after printing without pretending that the registration feature is a structural joint.

## Scope

- single-axis split plans only;
- two deterministic cylindrical registration pins per supported seam;
- pin/pocket sizing derived conservatively from the selected nozzle;
- explicit per-side clearance;
- engagement bounded by both adjacent piece envelope lengths;
- exact positive-volume corridor probe using the final OpenCascade B-Rep;
- only full-material corridors may proceed;
- male pin generated by exact fuse;
- female pocket generated by exact cut;
- post-Boolean pieces must remain valid single solids;
- total output volume must match the analytically expected pin-minus-clearance volume delta;
- derived manufacturing projection only; `CadProject` is not mutated.

## Current heuristic

For a valid nozzle diameter `n`:

- pin diameter = `max(2.0 mm, 5n)`;
- per-side clearance = `max(0.15 mm, 0.5n)`;
- pocket diameter = pin diameter + twice the per-side clearance;
- desired engagement = `max(4.0 mm, 10n)`, additionally bounded by adjacent piece depth;
- two pins are placed at one-third and two-thirds of the longer seam-envelope tangent span;
- seam envelopes that cannot satisfy conservative margin rules fail closed.

These are registration heuristics, not universal fit standards. Material/process calibration remains future work.

## Safety boundaries

The system must say **registration/alignment**, not structural reinforcement.

It does not claim:

- tensile/shear/bending strength;
- fatigue life;
- watertightness;
- press-fit quality;
- material-specific shrink compensation;
- multi-axis grid joint collision safety;
- fastener replacement;
- load-bearing suitability.

Multi-axis grid alignment is intentionally unsupported in this slice.

## Evidence

- pure deterministic planner regression;
- too-small seam fails closed;
- grid split fails closed;
- exact smoke proves a full material corridor can be validated by positive intersection volume;
- exact smoke proves male fuse + female pocket cut remain valid;
- TypeScript/unit/exact/build gate required before UI exposure.

## Human gate

Do not expose/accept this as a user-facing manufacturing feature until the aligned multi-object 3MF path is integrated and visually checked in a slicer. Flat Split 3MF acceptance does not automatically accept registration-pin geometry.
